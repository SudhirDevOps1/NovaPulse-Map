Example 5 — Advanced

Everything in the library, enabled at once: per-node sparklines, p95 latency, trend arrows, live polling with exponential backoff, search, status filters, sortable columns, a live theme switch, JSON export, and incident detection.

This page tries the dev server's api/probes.json first. When that is not available — on GitHub Pages, in CI, or opened straight from disk — it falls back to probe-sim.js, an in-page simulator with the same response shape. The badge on the right says which one is live, so the demo never silently pretends to be connected.
