Example 4 — Live JSON feed

The production pattern. Point data-nodes-url at your telemetry endpoint and the widget self-updates. The built-in latency jitter is switched off (live="false") so it never fights your real data.

This demo is served by scripts/serve.mjs, which exposes a simulated /api/probes.json endpoint. Swap it for your own URL. polling…

Feed protocol

GET /api/probes.json

// either a bare array…
[
  { "id":"iad", "name":"Ashburn", "region":"us-east",
    "lat":39.0438, "lon":-77.4874,
    "status":"Operational", "latency":12 }
]

// …or wrapped, which lets you add metadata later without a breaking change
{
  "generatedAt": "2026-10-08T18:04:11Z",
  "nodes": [ { … } ]
}
