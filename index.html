Quick start

One attribute and two script tags. Auto-init scans the DOM on DOMContentLoaded. Keep the ?v= query string: without it a CDN will happily hand a returning visitor an older bundle, and the page then reports a version that does not match its own features. 

<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css" />
<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>
<script src="./dist/novapulse.min.js?v=1.1.0"></script>

<div data-novapulse-map
     data-nodes-url="/data/probes.json"
     data-height="420"
     data-show-stats="true"
     data-show-table="true"></div>

What's in the box

Everything is opt-in. The defaults preserve the minimal 1.0 behaviour exactly.

Latency

Sparklines & p95

A bounded per-node sample history drawn as inline SVG. p50, p95 and p99, because a mean hides tail latency.

Live

Polling + backoff

The interval doubles on failure, caps at 32×, and resets the instant a poll succeeds.

Alerts

Incident detection

statuschange fires once per real transition. recovered fires on return to operational.

Interaction

Search, filter, sort

Search across name, region, country and provider. Keyboard-sortable columns with aria-sort.

Cartography

Zoom-aware clustering

Nodes that would overlap merge into one marker at their centroid and split apart on zoom.

Integration

Embeds anywhere

Script tag, npm, React, Vue, or an iframe driven over postMessage.

Core API

Every method is safe to call after destroy() — it becomes a no-op rather than throwing.

MethodReturnsDoes
setNodes(nodes)thisReplace every node
getNode(id)node | nullOne node, as a copy
setLive(on)thisPause or resume probing
poll(url)PromiseFetch the feed once
startPolling(url)thisPoll now, then on schedule
setSearch(q)thisFilter the table
setSort(key, dir)thisSort the table
getPercentiles(id)object | nullmin, p50, p95, p99, max, mean
setTheme(theme)thisSwap tiles and CSS variables
exportJSON()objectState plus history, downloads too
destroy()voidTimers, listeners and DOM all released
on(event, fn)functionSubscribe; returns an unsubscriber

Feed format

Any endpoint returning JSON works. Omit latency and it is treated as unknown, never 0 ms — a fabricated zero would make a broken probe look like the fastest node on the map. 

[
  { "id": "iad", "name": "Ashburn", "region": "us-east", "country": "US",
    "lat": 39.0438, "lon": -77.4874,
    "status": "Operational", "latency": 12,
    "uptime": 99.97, "note": "" }
]
