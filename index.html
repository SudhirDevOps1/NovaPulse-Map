What problem it solves

Most status pages draw an abstract SVG. That is fine until someone asks “is it me or the network?” — then a decorative blob is useless, because it shows no geography. This is the same information on a real map.

Where

Real coordinates

Every node at its true lat/long, on real OSM tiles. A slow Sydney and a slow Singapore are visibly different problems.

How bad

Distribution, not just mean

Sparklines plus p50/p95/p99 per node. A mean of 40 ms can hide a p95 of 380 ms, which is the number users feel.

Tappable

Zoom-aware clustering

Ashburn and New York sit 11 px apart at world zoom. They merge into one marker and split as you zoom, instead of becoming one unusable target.

Honest

Unknown is not zero

A missing latency renders as — and records a gap. Fabricated zeros make a dead probe look like the fastest node on the map.

Loud

Incident events

statuschange fires once per real transition, and recovered on the way back. Hook it to PagerDuty or Slack.

Cheap

No key, no cost

Keyless OSM tiles, ~18 KB gzipped, zero runtime dependencies beyond Leaflet. Nothing to provision, nothing to expire.

Install

Pick your path. All of them need Leaflet first — it is a peer dependency and is never bundled.

HTML — script tags 
<!-- 1. Leaflet CSS -->
<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css" />

<!-- 2. a container -->
<div id="map" style="height:420px"></div>

<!-- 3. Leaflet, then NovaPulse -->
<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>
<script src="https://unpkg.com/novapulse-edge-map/dist/novapulse.min.js"></script>

<script>
  new NovaPulseMap({ container: '#map', nodes: [] });
</script>

No JavaScript on the page at all. One attribute; the library scans the DOM on DOMContentLoaded.

HTML — declarative 
<div data-novapulse-map
     data-nodes-url="data/probes.json"
     data-height="420"
     data-show-stats="true"
     data-show-table="true"
     data-show-controls="true">
</div>

Every data-* attribute maps to an option, kebab-cased.

The library owns its DOM, so hand it a ref — not JSX children. Always destroy() on unmount or the interval keeps running.

jsx 
import { useEffect, useRef } from 'react';
import 'leaflet/dist/leaflet.css';
import 'novapulse-edge-map/style.css';
import NovaPulseMap from 'novapulse-edge-map';

export function ProbeMap({ nodes }) {
  const host = useRef(null);
  const mapRef = useRef(null);

  useEffect(() => {
    mapRef.current = new NovaPulseMap({
      container: host.current,
      nodes,
      height: 440,
      showStats: true,
      showTable: true
    });
    return () => mapRef.current.destroy();   // required
  }, []);                                     // mount once

  useEffect(() => {
    mapRef.current?.setNodes(nodes);
  }, [nodes]);

  return <div ref={host} />;
}
vue 
<script setup>
import { onMounted, onBeforeUnmount, ref, watch } from 'vue';
import 'leaflet/dist/leaflet.css';
import 'novapulse-edge-map/style.css';
import NovaPulseMap from 'novapulse-edge-map';

const props = defineProps({ nodes: { type: Array, required: true } });
const host = ref(null);
let map = null;

onMounted(() => {
  map = new NovaPulseMap({
    container: host.value, nodes: props.nodes, height: 440
  });
});

watch(() => props.nodes, (n) => map?.setNodes(n));

onBeforeUnmount(() => map?.destroy());
</script>

<template><div ref="host" /></template>

For a third-party host, a docs site, or anywhere CSS would collide. Host the widget yourself, then drive it over postMessage.

HTML — host page 
<iframe src="/widget.html" width="100%" height="620"
        title="Edge status" loading="lazy"></iframe>

<script>
  const frame = document.querySelector('iframe');
  const send = (m) =>
    frame.contentWindow.postMessage({ __novaPulse: 1, ...m }, '*');

  send({ type: 'getState' });
  send({ type: 'setLive', live: false });
  send({ type: 'setNodes', nodes: [...] });

  addEventListener('message', (ev) => {
    if (ev.data?.__novaPulse === 1 && ev.data.type === 'state') {
      console.log(ev.data.state.status);
    }
  });
</script>

Feed format

Any endpoint returning JSON works — a bare array, or wrapped in { nodes: [...] } so you can add metadata later without breaking anything.

JSON 
{
  "generatedAt": "2026-10-08T18:04:11Z",
  "nodes": [
    {
      "id": "iad",
      "name": "Ashburn",
      "region": "us-east",
      "country": "US",
      "provider": "Example Telecom",
      "lat": 39.0438,
      "lon": -77.4874,
      "status": "Operational",
      "latency": 12,
      "uptime": 99.97,
      "note": ""
    }
  ]
}

Omit latency and it is treated as unknown, never 0 ms. Bad coordinates and unknown statuses are dropped rather than throwing, so one malformed row cannot take the map down.
